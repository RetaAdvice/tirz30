Injection and Dosage Instructions

Tirzepatide 30mg

!
Important Tirzepatide is the generic active drug name for Mounjaro. To achieve a 2.5mg dose with this pen, set the pen to "25". For a 5.0mg dose, set to "50". Detailed dosage schedules are widely available online.

Instructions

Follow each step in sequence

  1. Add the needle tip to the Reta Pen by pushing it on first, then twisting until it is secure
  2. Prime the needle with 2-3 clicks to ensure no air is in the cartridge
  3. Select suitable injection site (belly fat, upper thigh or behind the upper arm)
  4. Clean the injection site with the supplied Alcohol wipes
  5. Set the pen to your desired dosage (see notice above for more details). This pen can be wound back if taken too far
  6. Press and hold the plunger until it reaches the base
  7. Leave in the skin for 5 seconds before removing and safely disposing of the tip
